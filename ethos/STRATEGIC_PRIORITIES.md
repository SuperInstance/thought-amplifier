## The one judgment call that dominates everything else

Before the ranked list: the project is at a fork, and every item below is downstream of which branch gets taken.

**Branch A:** keep defending "DCA is a new subfield." This requires winning an argument against seven uncited, directly competing, published systems (Voyager, Reflexion, TextGrad, DSPy, Generative Agents, SOAR chunking, FrugalGPT) — several of which do *exactly* what the dissertation claims is novel, one of which (SOAR) published the reflex-compiler idea in 1986. That argument is not currently winnable with the evidence on hand, and manufacturing the evidence (a rigorous ablation showing the Conductor beats random intervention, at publication-grade statistical power) is realistically **months**, not the "six weeks" the review's optimistic framing suggests, given the GPU can't currently sustain a 20-sample baseline run without losing its CUDA context.

**Branch B:** reframe as "Thought Amplifier: a cost-bounded, interpretable architecture for continuous LLM-directed agents" — exactly the paper the reviewer says they'd accept. C1, C2, and C5 are real, measurable, achievable engineering claims. The sham-arm mechanism is a genuine methodological contribution regardless of subfield status. This paper is reachable in weeks, not months, because it doesn't need the Conductor-vs-random result to be true — it only needs the engineering to work.

Every item below is scored assuming **Branch B**, because Branch A's value is contingent on an experiment (#2 below) that hasn't been run yet and may not support it. If #2 comes back positive, Branch A reopens — but that's a decision to make *after* the data exists, not before. I'd recommend this reframe explicitly rather than let it happen by inertia; it changes what "done" means for sections 1, 2, and 13 of the dissertation.
